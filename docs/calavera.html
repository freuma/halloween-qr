La calavera

Pulsa para dejarla lista. La pantalla se queda negra: la calavera aparecerá sola, con un grito, cuando oiga ruido o un golpe, y de vez en cuando por sorpresa.

El navegador pedirá permiso para usar el micrófono. El sonido no se graba ni se envía a ningún sitio: solo se mide el volumen.
